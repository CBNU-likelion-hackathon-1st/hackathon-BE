# hackathon-BE
충북대학교 멋쟁이사자처럼 해커톤 1조 백엔드 레포지토리입니다.


## 커밋 메시지 타입

feat: 새로운 기능 추가<br>
fix: 버그 수정<br>
docs: 문서 변경<br>
style: 코드 포맷팅, 세미콜론 누락 등 코드 변경이 없는 경우<br>
refactor: 코드 리팩토링 (기능 변경 없음)<br>
test: 누락된 테스트 추가 또는 기존 테스트 수정<br>
chore: 빌드 프로세스 또는 보조 도구 수정 (라이브러리 추가 등)<br>
perf: 성능 향상 관련 변경<br>
build: 빌드 관련 파일 변경<br>
